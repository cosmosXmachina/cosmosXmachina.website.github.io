# cosmosXmachina Design Directions

These images are exploratory visual proposals, not implemented pages. Every direction preserves the esoteric alchemical identity, existing business content and single-page behavior.

1. `00-current.png`: implemented website after the alternating-background, two-symbol and hover-shine changes.
2. `01-hermetic-observatory.png`: editorial astronomy, quiet authority and precise celestial instrumentation.
3. `02-prismatic-glass-atelier.png`: bright-first crystalline laboratory with a dark technical interlude.
4. `03-arcane-editorial-codex.png`: cool-paper illuminated manuscript translated into a modern software interface.
5. `04-digital-cathedral.png`: monumental, cinematic architecture with restrained service presentation.
6. `05-transmutation-system-map.png`: information-design-led transformation path from operational chaos to digital order.

The concept images may contain illustrative details that would need to be translated into accessible HTML/CSS and procedural Three.js rather than copied literally.
